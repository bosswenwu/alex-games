# Alex 的游戏厅

六款浏览器游戏的统一入口：Minecraft、深渊圣所、zhuzhiliao、Haven、Nebula Strike 和三国塔防。

## 本地运行

在本目录执行：

```powershell
npx serve .
```

然后打开终端显示的本地地址。不要直接双击 HTML；摄像头与部分模块需要 HTTP/HTTPS 环境。

## 游戏路径

- `/games/minecraft/`
- `/games/abyss/`
- `/games/zhuzhiliao/`
- `/games/haven/`
- `/games/nebula/`
- `/games/three-kingdoms/`

## 部署

这是纯静态网站，可部署到 Vercel、Netlify 或 GitHub Pages。
