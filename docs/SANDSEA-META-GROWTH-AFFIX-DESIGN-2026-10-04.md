# 沙海奇境：局外养成与装备词缀系统设计

**日期：**2026-10-04
**评审基线：**仓库 `bosswenwu/alex-games`，本地 `main` 基线 `3476b3ed48e72e3a27455f87b46f9e4d06be0e7e`
**适用范围：**遗迹远征作为可重复的短局玩法；此文是建议方案，不改变当前游戏战斗数值。

## 1. 结论摘要

建议把深度做成两层，而不是继续叠加全局伤害：

1. **局外“遗迹研习”**：确定性、可规划、永久保留；玩家选路线、不是抽随机属性。
2. **局内装备词缀**：从远征中获取、撤离后带出；随机组合形成流派，能拆解、重铸和逐步替换。

新数值应**只在遗迹远征中生效**，避免和开放世界的等级伤害、能量核心、永久附魔、护甲、神话被动无限相乘。首发只做 2 个装备槽（**武器刻印、护符**）；护甲仍沿用现有 `armor`，避免同时重做装备 UI、耐久和护甲算法。

> 当前已有锋利、火焰附加、横扫之刃、击退四种永久附魔（等级上限分别为 V、II、III、II），作用于剑与塞特之锤；能量核心还可购买永久 `dmgMul +0.08`。因此新系统不应再加“全局攻击 +X%”主线，否则会加快数值膨胀。

## 2. 当前系统基线与设计约束

| 已有系统 | 当前行为 | 设计含义 |
|---|---|---|
| 玩家等级 | 提升攻击倍率和最大生命 | 新专精不再给无条件全局攻击/生命成长 |
| 能量核心 | 可换永久强化；沙步熟练和回砂反击各 3 级 | 远征专精应偏向地图、容错、条件触发，不重复复制战技树 |
| 永久附魔 | 锋利 / 火焰 / 横扫 / 击退，适用于剑和锤 | 把它视为开放世界长期底盘；远征词缀只在远征生效 |
| 装备耐久 | 武器磨损、可修理，低耐久也保留最低威力 | MVP 不引入多套装备耐久或破坏装备 |
| 文物碎片 | 交易、祝福、附魔等已有用途 | 不再把文物碎片作为唯一新系统货币，避免老功能被挤兑 |
| 存档 | 单文件浏览器游戏，进度写入本地存档并有老档兼容惯例 | 局外进度加版本化字段；缺字段按空进度读取，验证后再保存 |

**重要前置：**将能量核心的永久伤害强化作为单独平衡事项复核其购买上限与累计增长，再开启远征装备掉落；不要用新的词缀掩盖原本的倍率膨胀。迁移旧存档时不回收玩家已有强化、不降级装备。

## 3. 玩家循环与奖励数值

### 3.1 一局结构

- 一局目标时长：**8–12 分钟**；3 个探索段，每段 2–3 分钟，末段精英/首领约 2 分钟。
- 每段结束给一个路线选择（安全路线、陷阱路线或精英路线），下一段奖励与风险不同。
- 每段最多掉 1 件候选遗物；第三段首领箱最低保证 **精制**品质。
- 解密机关通过后开启侧室或拿到远征箱；正确解一次只发一次奖励。错误输入不扣血、不耗道具。
- 玩家可在段间撤离；已结算到“安全袋”的铭文保留，未撤离的装备候选不会自动入库。

### 3.2 复用现有货币：能量核心

**不新增货币。**远征段落奖励与局外专精统一使用现有 `cores` 能量核心；文物碎片仍作为遗物拆解/重铸材料。这样 P3 战技和 P4 研习共享一个资源闭环，但二者的获取速度和花费都必须纳入模拟。

| 事件 | 核心 | 处理时机 |
|---|---:|---|
| 清理第 1 段 | +1 | 段结算后立即入安全袋 |
| 清理第 2 段 | +1 | 段结算后立即入安全袋 |
| 清理第 3 段并撤离 | +2 | 完成撤离时结算 |
| 三条固定远征路线各首次完成 | +1 | 每条固定 routeId 只给一次，不跟随机 seed 变化重复发 |
| 死亡 / 主动撤离 | 保留已入安全袋部分 | 候选装备/未结算宝箱不带出 |

普通满流程约 **4 个核心**，固定路线的首次满流程约 **5 个核心**。段落核心在结算点直接写入现有货币，玩家不会因最终首领失败而失去前段收益；装备候选仍需成功撤离才能带出。

### 3.3 局外专精树

三条路线，每条 4 阶；每阶买一次，解锁顺序固定，不随机。阶级成本建议 **2 / 3 / 5 / 7 个现有能量核心**，单支满级 17，全树 51。按每次满流程约 4 个核心估算，约 **13 次成功远征**可完成全树；第一小时至少能点亮 2–4 个节点。此成长与现有 P3 战技竞争同一钱包，首发前需检查玩家是否有可理解的购买排序。

| 路线 / 阶 | 成本 | 效果（仅遗迹远征） |
|---|---:|---|
| **测绘者 I：廊道记录** | 2 | 每局显示第一段两条路线的风险等级，不显示宝箱内容 |
| **测绘者 II：壁画释读** | 3 | 每个机关给一次额外文字提示，不直接展示答案 |
| **测绘者 III：隐匿侧室** | 5 | 每局一次，显示最近侧室入口方向；不增加首领掉落 |
| **测绘者 IV：文书封存** | 7 | 连续完成 3 局后额外 +1 核心；失败不会重置计数 |
| **守墓者 I：干粮** | 2 | 每局开始回复 2 点生命；不突破最大生命值 |
| **守墓者 II：盐甲** | 3 | 每个探索段第一次受击伤害 -5% |
| **守墓者 III：应急绷带** | 5 | 每局一次，生命低于 25% 时自动回复 4 点；不复活、不清负面状态 |
| **守墓者 IV：安魂** | 7 | 首领击败后撤离期间受击 -8%；不作用于首领战 |
| **沙步者 I：稳足** | 2 | 远征内沙步冷却 -0.2 秒；只对远征副本生效 |
| **沙步者 II：回砂** | 3 | 成功闪避后 2 秒内的首次近战 +5%，8 秒内最多触发一次 |
| **沙步者 III：破势** | 5 | 对精英 +6% 伤害，对普通敌人不加伤害 |
| **沙步者 IV：猎首** | 7 | 首领战开始后的前 4 秒 +6% 伤害；每场首领战一次 |

**平衡目标：**远征专精带来的总体战斗效率提升在同等装备下约 **10–15%**，更大收益来自少踩陷阱、读懂路径和更稳定撤离；全局开放世界伤害不变。守墓者的减伤和治疗只在远征生效，不叠加成永久血量上限。

## 4. 装备词缀系统

### 4.1 槽位、品质与规则

MVP 使用两个独立于热栏的槽位：

- **武器刻印**：影响剑/锤近战，但只在遗迹远征生效。
- **护符**：减伤、线索、撤离或掉落类效果。

MVP 不加护甲装备槽；已有护甲等级仍然有效。每件装备都有固定底材/槽位和可重铸词缀，不改变现有剑/锤耐久。

| 品质 | 第 1 段掉率 | 第 2 段掉率 | 首领箱掉率 | 词缀数 |
|---|---:|---:|---:|---:|
| 旧制 | 70% | 55% | 40% | 1 条 I 阶 |
| 精制 | 25% | 32% | 35% | 1 条 II 阶 |
| 古代 | 5% | 11% | 20% | 2 条，至少 1 条 II 阶 |
| 神话 | 0% | 2% | 5% | 3 条，含 1 条专属效果 |

- 首领箱至少古代品质的保底规则建议改为 **“通关第 3 段时，至少精制；连续 4 次首领箱未出古代则下一次保底古代”**，神话品质不设短期保底。
- 词缀不能重复同一 `group`，不出现负面词缀，不抽到当前槽位无效的词缀。
- 物品 ID 用 `runSeed + roomIndex + lootIndex` 生成，重载不会重新掷出另一件装备。
- 退出/死亡时：已撤离装备永久保留；尚未领取的候选装备消失。局外专精和现有能量核心不丢失。

### 4.2 首发词缀池与阶级值

数值表里的 I / II / III 是词缀自身阶级；装备品质决定能出现哪些阶级。下列数值是**第一轮平衡初值**，不是已经写入游戏的实装值。

| 槽位 | 词缀 | I / II / III | 触发 / 限制 |
|---|---|---|---|
| 武器 | 砂刃 | 近战 +3% / +5% / +7% | 远征内；同类只取最高一条 |
| 武器 | 回砂余势 | 成功闪避后下一击 +5% / +8% / +11% | 2 秒内；8 秒触发冷却；不作用于范围副伤害 |
| 武器 | 破甲印 | 对精英/首领 +4% / +6% / +8% | 不作用于普通敌人；与沙步者专精合并后设封顶 |
| 武器 | 烈阳余烬 | 点燃 +0.4 / +0.7 / +1.0 秒 | 与永久火焰附加不叠加持续时间，取较长者 |
| 护符 | 守墓回响 | 每段首次受击 -6% / -9% / -12% | 每段一次；同类只取最高值 |
| 护符 | 沙步回声 | 沙步冷却 -0.10 / -0.15 / -0.20 秒 | 总冷却缩减封顶 35%，含现有熟练等级 |
| 护符 | 壁画慧眼 | 每个机关额外 1 / 1 / 2 条文字提示 | 不揭示答案、不自动解题 |
| 护符 | 收藏者印记 | +3% / +5% / +7% 遗物箱额外文物碎片概率 | 每局最多额外掉 1 份，防止刷无限材料 |
| 护符 | 撤离者恩典 | 撤离后回复 2 / 3 / 4 点生命 | 不超过最大生命；只在成功撤离时生效 |

### 4.3 封顶与流派约束

- **战斗总预算：**同等玩家等级下，远征装备令稳定 DPS 最多提升约 **15%**；瞬时爆发可以更高，但需要闪避/首领窗口等条件并受触发冷却约束。
- **伤害减免：**远征内词缀提供的减伤合计封顶 **15%**；已有护甲减伤先按现有函数计算，再乘远征词缀系数，避免简单相加超过预算。
- **冷却缩减：**沙步总冷却缩减（含已有沙步熟练）不超过基础值的 **35%**；显示最终秒数而不只显示百分比。
- **奖励加成：**每局最多额外 1 份既有材料（优先文物碎片）；不额外产出核心，概率不能无限乘算，专精与词缀取相加后封顶。
- **独占组：**`melee_damage`、`elite_damage`、`damage_reduction`、`sandstep_cdr`、`loot_bonus` 等组最多装备一条，重复掉落允许拆解，不允许数值叠满。
- 这些封顶必须在统一的 `getExpeditionModifiers()` 中集中计算，不能在多个伤害分支里各自叠一次。

### 4.4 拆解、重铸与重复物品保护

重复掉落要转化为可控进度，而不是占满背包：

| 拆解品质 | 文物碎片（既有货币/材料） |
|---|---:|
| 旧制 / 精制 / 古代 / 神话 | 1 / 2 / 4 / 8 |

- 重铸一件物品的**一条**词缀：3 文物碎片；锁定另一条后重铸：另加 2 文物碎片。
- 重铸结果不能与该物品已有词缀 `group` 冲突；最多连续两次得到相同词缀后，下一次排除该词缀。
- 拆解返还既有文物碎片；重铸会与祭坛/商队/祝福等现有用途竞争，需设置每次远征的获取上限并做经济模拟；不创建“刻印砂”新字段。
- 新手第一局强制给武器槽或护符槽当前为空的一件精制装备；首领保底优先补空槽。

## 5. 构建示例

| 流派 | 专精 | 装备 | 操作循环 |
|---|---|---|---|
| **沙步反击** | 沙步者 I–II | 砂刃 II + 回砂余势 II | 等待预警、闪避后 2 秒内打一记主击，避免乱挥消耗窗口 |
| **稳健探索** | 测绘者 I–III、守墓者 II | 壁画慧眼 II + 守墓回响 II | 先辨路再开机关，降低失误与每段首击损失 |
| **首领猎手** | 沙步者 III–IV | 破甲印 III + 撤离者恩典 I | 保留技能窗口打首领，击败后稳妥撤离 |

这些构建的强弱差异应通过条件/工具性体现，而不是“红装全方面更强”。不应存在必须刷到神话品质才能打过远征首领的门槛。

## 7. 可实施拆分与验收

### PR A：专精与存档（不加随机装备）

1. 新增 `normalizeMeta()` / `collectMetaSave()`，旧档读取缺字段视为空进度。
2. 新增三条专精数据表、价格、前置阶级与只读效果计算器。
3. 用现有 `cores` 驱动专精 UI；购买先校验余额/前置项，再扣款、加级、保存，任何失败不扣币；不新增货币字段。
4. 测试：老档读取、坏数据夹取、购买事务原子性、成本/上限、重载保持、没有开放世界伤害变化。

**PR A 验收：**每个节点都可通过 UI 买到且只买一次；重复点击不双扣；刷新恢复；`collectSave()` 旧字段值不变；三个分支均至少有 2 个可选 build 路线。

### PR B：词缀定义与掉落

1. 建立纯数据 `AFFIX_DEFS`、品质权重、独占组和 seeded RNG。
2. 在每段结算产生候选装备；一局同一宝箱 ID 不重新掷骰。
3. 先做装备比较/领取/拆解，再做重铸；装备不进热栏、不影响方块栈。
4. 测试：固定种子结果一致、槽位有效、没有重复 group、掉率总和 100%、保底计数可迁移、重复 ID 不发双份奖励。

**PR B 验收：**已有永久附魔保留；所有新词缀只在 `expeditionState.active` 时有效；非远征战斗伤害与基线逐字节/逐断言一致。

### PR C：战斗接线与调优

1. 在唯一伤害聚合入口叠加远征 modifier；闪避触发只认现有成功闪避信号，不认普通位移。
2. 每个段进入时重置“每段一次”的触发器；退出/死亡时关闭会话，永久装备仍保留。
3. 自测：剑/锤、普通/精英/首领、击退/横扫副伤害、沙步 cooldown、背包/存档、reload、窗口窄屏、键鼠/触控。
4. 两轮内部平衡：先不改概率，再只改数值；记录首通率、平均时长、撤离率、首领死亡原因、可选流派占比。

**首轮观察目标（假设，需要真人数据验证）：**单局 8–12 分钟；首次通关率 45–60%；失败后仍有至少 1 个保底成长；没有单一词缀 build 占有效通关率 70% 以上；玩家能在装备面板读懂触发条件和剩余冷却。

## 8. 风险与决定项

- **单机存档可编辑：**前端单机无法防止玩家改 localStorage；本方案目标是稳定体验，不承诺服务端反作弊。
- **跨设备：**当前进度基于浏览器本地存储；“局外”不是账号云同步。如果未来要求跨设备，需要先确定服务端/账号存档方向，不能仅靠本地字段实现。
- **原有永久成长：**在开放局外成长前，先核算玩家等级、核心强化、锋利 V、护甲上限组合；新装备只在远征内生效，作为隔离舱。
- **首发边界：**一次实现“专精 + 背包装备 + 三个掉落面板”风险太高；建议先 A，再 B，再 C；每个阶段均可单独关闭 feature flag。

## 9. 与三符号机关前端模块的接口

本次已提供 UI 控制器接口：

> **前端答案可见性边界：**“机关 UI 不揭示答案”仅表示面板不把答案显示给玩家；`solution` 必须驻留浏览器内存供本地判定，使用开发者工具的玩家可以检查它。本地单机不提供服务器级保密或反作弊保证。

```js
openRuinGlyphPanel({
  solution: [2, 0, 1],          // 本轮合法排列，由远征结构/种子/线索生成
  clueText: "廊柱上的刻痕提示……",
  onSolved: () => {             // 此处校验 rewardId 未领取，再开侧室/结算一次奖励
    // markRewardClaimed(runId, chamberId);
  },
  onCancel: () => {}            // 玩家 Esc/点遮罩离开，不惩罚
});
```

机关模块自身不揭示 `solution`，不保存答案、不发货币、不增加尝试惩罚。调用方负责线索展示、门/侧室状态与奖励幂等；将 `solution` 与线索对应关系加入远征结构生成器的固定种子测试。
