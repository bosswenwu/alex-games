## 1. 准备与记录

1. 从 `main` 当前 commit 运行本地版本：`python3 -m http.server 8000`（仓库根目录），在桌面浏览器打开 `http://localhost:8000/games/minecraft/?seed=424242`。真机可使用同一版本已部署地址，但记录部署 URL、commit，并避免缓存旧脚本。也可以使用真实世界种子找自然刷新的圣甲虫；**固定种子不保证附近必有圣甲虫**。先确认标题页加载完、进入游戏，按 `N` 跳过新手引导（若出现）；正常进入游戏无需改开发者变量。
2. 记录：测试者、日期、commit、设备型号、OS、浏览器版本、GPU/WebGL renderer、桌面/触屏、视口 CSS 宽高/DPR、画质档、渲染距离、种子、是否载入旧档。桌面准入至少 1280×720；触屏至少一台真实横屏设备（参考 844×390 CSS 像素）；390×844 竖屏仅查旋转提示，**不期待竖屏可玩**。如未取得真实设备，在记录中写“未测”。
3. 桌面：`C` 为沙步；`W/A/S/D` 移动，左键攻击（先选可用近战武器，锤/剑用现有快捷栏）；触屏：按“沙步”按钮并用实际触摸攻击。`Space` 不是沙步键。需要对照数值时只读 `window.__game.sandStep`、`window.__game.mobs`，不要在自然点测里用脚本篡改敌人状态。
4. 遇敌路径：在沙漠/金字塔附近找**自然生成**的圣甲虫，留足 `1.3–8.5` 左右的起手距离及宽敞侧闪空间；若长时间找不到，请记录“自然遭遇未覆盖”，独立使用可复现布景脚本只做逻辑/画面检查，不能声称完成真人点测。

## 3. 审核门槛与处置

- **P0 阻断 / 立即修复并视影响考虑回滚**：游戏打不开/白屏、频繁运行时错误；可在无预警或取消后被圣甲虫命中；一次冲锋重复伤害；无限/跨目标反击、重锤 AOE 错误加成；旧档损坏/不能启动；触屏沙步无法操作或 HUD 完全不可读。附可复现种子、设备、步骤、录像、控制台日志；在独立修复 PR 中增加确定性测试。
- **P1 必须决定并形成跟进 PR**：5–10 次有效尝试中反复出现“已看见/躲开仍判中”的误判，或低端参考真机 3 只遭遇时相对同设备匹配基线 p95 帧时恶化 >10%、连续约 5 秒低于 30 FPS；预警低画质无法辨认、粒子持续不回落。阈值为下一周期**建议验收目标**，只有参考机与样本可比才可作正式判断。先定位帧耗或单个战斗参数，再一项一项修改。
