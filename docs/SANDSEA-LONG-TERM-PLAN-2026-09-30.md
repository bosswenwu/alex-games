# 沙海奇境：战斗可读性切片与长期迭代计划（2026-09-30）

## 目标与执行边界

沿着 **优化基础 → 丰富战斗与成长玩法 → 扩展关卡 → 全面检查 → PR 交付** 的顺序推进沙海奇境。每个阶段都通过 GitHub Issue #11 单独认领，每次只实现一个可测量、可回滚的小切片。

硬性约束：`games/minecraft/index.html` 单文件、零外部依赖、现有旧存档可读；本轮没有新增存档字段、快捷键、方块或资产。PR 可以创建和更新，但合并须等用户明确授权。

## P0｜战斗可读性垂直切片（第十七轮，已实现并验收）

本轮范围只包含 `games/minecraft/index.html`：圣甲虫蓄力预警—锁向冲锋—收招、冲锋攻击识别、沙步精准反击、反馈可读性及其确定性回归测试。

- **攻击节奏：**圣甲虫预警后才冲锋；预警时锁定方向。受击、失去视线、目标离开距离或方向条件时取消并收招，不应生成幽灵命中。冲锋伤害仍走 `foeStrike()`。
- **明确预警：**蓄力时圣甲虫显示暖金高亮，并在周围生成亮色浮空粒子环；粒子使用现有上限和 WebGL 绘制路径，不增加渲染依赖或着色器管线。
- **精准反击：**只有在沙步闪避窗内避开带圣甲虫冲锋标记的攻击，才获得 2 秒、绑定同一目标的一次性反击机会。下一次同目标近战主目标伤害增加约 35%（向上取整、最多 +3）；重锤范围副伤害、远程与环境伤害不吃加成。普通敌击不授予该资格。
- **状态与兼容：**反击状态仅运行时；超时、目标离场、暂停、死亡、重生或新世界时清理；不改变存档 schema。
- **回归结果：**完整 `node tools/headless.mjs selftest` 默认世界 **362/362 PASS**；固定种子 `?seed=424242` **362/362 PASS**。`git diff --check` 通过。
- **视觉结果：**无头 Chromium / SwiftShader 截图并目视检查 1280×720 桌面预警、844×390 横屏触屏反击、390×844 竖屏旋转提示；脚本布景运行未报告窗口错误。截图模拟状态，不代表真人闪避时机或真机触控验证。
- **交付状态：**当前分支为 `work/sandsea-scarab-telegraph-riposte-20260929`；本文件随该切片进入 PR。合并前仍需真人在桌面/触屏点测节奏与低端 GPU 帧耗。

## 每个切片的工程循环

1. 同步 `origin/main`、Issue #11、开放 PR 和 `AGENTS.md`；先声明范围及明确不改项。
2. 先写玩家体验、状态转移、数值边界、失败/取消条件、触屏呈现和存档影响。
3. 仅在单文件内做最小实现，复用现有状态和统一伤害入口，控制每帧分配。
4. 新增确定性测试覆盖正常路径、边界、打断、死亡/目标离场、存档兼容；运行全量 selftest 与固定种子回归。
5. 对桌面和相关触屏尺寸截图并实际目视；严格区分自动化、模拟触摸与真人点测。
6. 更新 `GAME-CHANGELOG.md`、追加 `BACKLOG.md` 接手记录；必要时更新本路线图。
7. 推送独立分支、创建单主题 PR；写清验证、存档/API/性能影响及未覆盖风险。**不自行合并。**
8. 获得用户合并授权后，再同步并检查 `main`，补记 Issue #11 的合并结果。

## 设计原则与未覆盖事项

- 以沙漠古文明探险为核心；新战斗和成长要相互服务，避免“系统很多但没有投入/回报闭环”。
- 不因候选路线同时启动多个阶段；先完成 P0，再由 Issue #11 协调认领 P1。
- SwiftShader 无头截图只能证明脚本化状态和布局，不代替真人判断真实操作窗口、低端 GPU 帧率或真实设备手感。上述点测明确保留给合并前审核。
- 以当前代码事实和 Issue #11 为协作来源；旧路线图中的历史诊断不能覆盖已实现功能。
