# 钢铁前线 · IRON VEIL — 扩展规格

## 核心系统

- 核心循环：进入战场 → 消灭波次敌军 → 三选一强化 → Boss 决战 → 战绩结算。
- 战斗：车体移动与炮塔独立瞄准；主炮有射速、伤害、弹速和命中反馈；冲刺与 EMP 为主动技能。
- 敌军：侦察车、突击坦克、重装坦克、远程炮车四类普通单位，以及一台带阶段技能的 Boss。
- 成长：每波结束提供三项不同强化，至少覆盖伤害、射速、装甲、护盾、机动和多重炮弹。
- 战场反馈：命中闪光、弹壳、火花、烟尘、爆炸、镜头震动、浮动数字和合成音效。
- 数值目标：普通战役五个波次；Boss 位于最终波；玩家生命 100、护盾 60；场上敌人、炮弹和粒子可调试读取。

## 操控与界面

- 电脑：WASD/方向键移动，鼠标瞄准，左键射击，Space 冲刺，E 释放 EMP，P/Esc 暂停。
- 触控：左侧虚拟摇杆移动；右侧 FIRE、EMP、BOOST 按钮；炮塔自动瞄准最近敌军。
- 流程：标题画面 → 作战 → 波次升级 → 暂停/继续 → 胜利或阵亡结算 → 再来一局。
- HUD：生命、护盾、技能冷却、波次、敌军数量、分数、连击、迷你雷达和操作提示。

## 工具与环境

- 单文件 HTML + Canvas 2D，无外部运行依赖，适合 GitHub Pages 子路径部署。
- 必须暴露 `window.__game`，可读取战斗状态并注入开始、射击、伤害、清场、跳波、选升级等动作。
- Playwright 必须真实执行开始、移动、瞄准、射击、受伤、EMP、升级与重开，并验证状态变化。

## 交付标准

- 桌面 1440×900 与移动 390×844 均不溢出；触控按钮可实际改变游戏状态。
- 首页使用真实运行截图作为封面，点击直接进入 `games/tank-strike/index.html`。
- 游戏与首页无控制台错误、无失败资源请求；公网部署后重复完整验收。
